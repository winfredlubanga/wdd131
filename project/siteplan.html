Website Planning Document

WDD 131 – Project Site Plan

Site Name

Kenya Travel Guide

The Kenya Travel Guide website is designed to promote tourism by providing useful information about popular destinations, travel tips, and cultural highlights across Kenya. The name was chosen because it is clear, descriptive, and immediately communicates the purpose of the site.

Optional domain: kenyatravelguide.org

Site Purpose

The purpose of this website is to serve as an informative travel resource for visitors interested in exploring Kenya. The site will provide destination highlights, travel advice, safety tips, and a contact form for inquiries. The website aims to help tourists plan enjoyable and informed trips.

Scenarios

  • Which tourist destinations in Kenya are best for first-time visitors?
  • What travel tips should I know before visiting Kenya?

Color Schema

The selected color palette is inspired by nature and tourism.

  • Dark Green (#1b5e20): Used for headings and navigation elements.
  • Light Beige (#f5f5dc): Used for background areas.
  • Accent Gold (#c9a227): Used for highlights and accents.

Typography

  • Montserrat: Used for headings.
  • Open Sans: Used for body text.
