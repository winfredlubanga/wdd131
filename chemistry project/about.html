About This Project

The Analytical Chemistry Formula Calculator was created as part of a web development course (WDD131) project. The goal is to demonstrate mastery of HTML, CSS, and JavaScript by building a dynamic and responsive web application.

Purpose

This web-based tool helps users accurately calculate molar masses, solution concentrations, and required masses for chemical solutions. It reduces human error and supports best laboratory practices.

Learning Outcomes

  • Apply analytical chemistry concepts in a real-world web application
  • Create interactive, dynamic elements using JavaScript
  • Design responsive and accessible web pages using HTML and CSS
  • Practice localStorage for storing user data
